修订 2 解决的审核问题

必须持续可见的提示被折叠 → 三通道；control / unresolved / progress 常驻，SSH 未确认不降级。

输入不足以推导展示 → 事实层 + 展示层，选择、确认、hint 与重置规则进展示状态。

网页键冲突 → domain:entityId:facet，全 facet 组合唯一性测试。

ExecutionStatus 误判为故障 → capability，只在设置页说明。

诊断在 E2E 默认开启、输入名称变化 → 启用判定改为开发服务器或显式变量；「会话消息」名称不变。

协议包边界、诊断落盘 → 协议包只放 DTO；raw 白名单、三出口、脱敏与上限。

决策

  1. 诊断仅在 pnpm dev 开发服务器或 WSL_DEBUG_STATUS=1 时可用；E2E 用的 build 产物默认关闭（修订 2 细化，已确认）。
  2. 健康终端在侧栏保留绿点。
  3. 同意修订 UX-CONTRACT / DESIGN 中要求常驻显示的条款。
  4. 设计已确认；按 implementation-prompt.md 在独立工作树 agent/status-surface 中实施（主代理 Opus 5.5 / high，子代理 Sonnet 5.5 / high）。
