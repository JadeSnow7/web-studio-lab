## 状态与导航

全局保留首页、空间、资源、会话、任务和底部设置。空间切换器、垂直标签、最多四窗格只属于空间页；没有“空间标签/工作坊”二级导航或顶部重复标签。首页、资源、任务和通知直接读取 Main 快照，shell 只拥有全局路由、侧栏和临时展示状态。个人对话保留原窄 chat 客户端；空间会话和任务不再使用旧演示 store。

左右栏拥有独立的 `pinned / hidden / peek`，仅 `pinned` 保存到本设备。首次左栏固定、通知未固定且收起。左图钉控制按钮列和空间标签整组；关闭不改固定偏好，取消固定收起，窄窗不改持久偏好。⌘B与左上标识按钮只控制左栏，⌥⌘B与右上铃铛只控制通知。按钮常驻标题栏并反映实际显隐，通知可访问名称保留未读数，0条不显示视觉角标。收起不占内容宽度；悬停与移出不切换。临时浮层通过触发器、内容区外部点击或Esc收起；Esc和关闭按钮恢复触发器焦点，内容区点击保留被点击控件的焦点；两栏可同时展开，点击另一栏或触发器不关闭原浮层。嵌套菜单和对话框优先处理关闭，不误关底层侧栏。专注模式下触发侧栏会退出专注并按原固定偏好正常展开。

空间名称只打开切换器。搜索不改变当前空间，点击结果才定位；清除搜索立即生效并返回搜索焦点。方向键、Home/End移动标签焦点，Enter打开；拖动排序有按钮等价操作。点击已显示标签聚焦原窗格，关闭窗格或标签不停止后台实例。明确关闭实例才结束其进程；后台资源可重开同一资源。

空间侧栏标题旁的网页、终端、会话按钮打开同一创建表单并预选对应类型；底部“新建标签”继续提供全部既有类型。终端仍需明确选择已配置环境，创建标签不自动连接；创建会话不自动发送消息。App 图标在当前空间尚无应用时提供“新建 App”，已有应用时提供“管理 App”，打开对话框后显式创建、启动、停止/取消或导出。App 命令绑定打开时的空间，忙态防止重复提交，状态与错误来自现有 workbench 命令和快照；关闭管理界面不停止应用。对话框沿用原生网页遮挡集合、原生 modal、Escape 与触发器焦点恢复规则，不新增业务状态所有者。

切标签/页面不结束 shell、重播输入或清空输出；隐藏终端不抢焦点，重新激活后获取输入焦点。主题只在设置页编辑，标明当前空间；白/暗/暖/系统按空间保存。空间的旧 `sidebarMode` 被整组 shell 偏好替代，不保留第二个固定入口。

多种浮层使用统一遮挡集合。打开前等待 Main 隐藏原生网页，再发布可点击浮层；最后一个浮层关闭后恢复。固定左右栏只触发实际矩形重测，不作为遮挡；标题栏触发器与原生网页实际矩形不重叠。1080px以下仅投影活动窗格，原分割树和后台实例不变，放宽恢复。

终端入口显式连接，starting/closing 禁用重复操作；仅 running 接收键盘和 resize。Ctrl-C 可通过键盘或可见按钮输入。关闭等待所属进程清理确认后显示已关闭；失败保持输出并展示错误，不能暗示成功。退出 shell 会关闭会话；再次连接创建新的 shell，不继承旧 cwd。

服务序号决定输出新旧；迟到查询与旧会话事件不能覆盖最新快照。服务保存有界尾部，outputOffset 与字符串采用同一 UTF-16 字符计数。界面按实例、PTY会话和绝对区间追加新尾段；重复文本但偏移增加仍是新输出。裁剪后存在重叠时保持终端状态，未读区间已丢失或实例更换时重建并明确提示缺口。

chat 在首页、会话页和空间会话标签显示相同 sandbox/cwd 来源；工具命令、输出、退出码和截断标记按需展开，非致命配置 warning 显示文字。服务不可用时保留输入、拒绝发送，不回退宿主 Codex。

通知只读展示运行事实，并定位准确的空间、会话和run。打开不自动已读，已读只保存阅读回执，不改变执行、检查或接受。任务历史、日志、diff和报告按指定运行展示；选择历史版本同步选择该版本的运行，若尚无运行则显示空态，不能回退到最新会话消息、工具或错误。没有证据明确说明，不能填入演示成功。现场采集通过网页关联会话入口到达，requestId冻结接收方，迟到结果不能污染其他请求。联系人位于会话板块。

窄窗口保持现有侧栏和布局 token；终端尺寸由可见内容区域计算。输入具有中文可访问名称，连接/关闭状态用 status，失败用 alert。真实 live 验证显式启用，fixture 输出不作为真实 Linux 或模型证据。

## 受管 App 的 AI 操控指示（2026-10-11）

依据[控制面设计](docs/design/2026-10-11-app-control-plane.md) §5。运行中的 TaskRun 在受管 App 网页上执行 UI 写动作或命令后，该网页的“沙箱应用”状态行下显示“AI 正在操控此页面（最近动作）”，状态来自 Main 的 `PreviewState.agentControl`，renderer 不自行推断。用户在该网页中点击或输入（不含滚动与指针移动）立即暂停 AI：状态改为“已暂停 AI 操控”，提供“允许 AI 继续”按钮（`browserAction: resumeAgent`），AI 期间的写动作返回 `paused_by_user`。AI 动作不调用网页或窗口聚焦，不抢占用户焦点；run 结束后指示消失。指示沿用 `workspace-inline-info` 与 `btn`，不新增浮层或全局入口；页面点选进行中视同用户操作，AI 写动作同样暂停。

AI 发起 `app.restart` 时只重建受管网页实例，不激活网页标签，不覆盖当前窗格或重启等待期间用户的新导航；用户在 App 管理界面显式启动应用仍打开对应网页。用户留在会话时，“取消回复”保持可达，取消须确认任务所属进程退出并保留已产生的项目修改。

## 账户资源、空间连接和会话参考（2026-10-10）

本节依据用户批准的 [RESOURCE-OWNERSHIP-1](docs/acceptance/resource-ownership-20261010/SPEC.md)，替代旧空间集合的归属及页面规则。实现和验证进度见[阶段记录](docs/acceptance/resource-ownership-20261010/README.md)。旧公开资源合同保留为历史；网页打开、捕获的来源与隔离限制继续有效。

- Main 是账户资源、收藏、空间连接和版本的唯一业务写入者。全局“我的资源”只列主动收藏，与当前空间无关；未收藏的空间内容仍属于用户账户。
- 资源页提供全部/开发资源/网页/文档分类、带清除按钮的搜索、分页、空态、无结果、错误和忙态。列表、表单与详情沿用页面内容滚动，窄窗长 URL/名称可换行。查询、分类和页码为 Electron 本地展示状态，不写入空间或浏览器 URL；删除或筛选后页码回到有效范围。
- 收藏链接只保存描述，不自动访问网络或保存正文；从空间收藏保留连接。取消收藏只影响个人列表。连接资源不自动打开页面或提供给 Agent；空间折叠资源区与活跃标签分开，后台实例另行显示状态。
- 保存正文快照核对实际页面身份、URL 或文件环境/路径，新增不可变版本；正文来自受控捕获/读取，renderer 不可自报。网页捕获失败不影响链接收藏。来源时间、摘要、截断及版本可查看，网页内容仍是非可信参考。
- 空间会话只取得已连接且明确选择的参考版本。个人会话只取得明确选择的收藏版本。发送前固定版本；新版内容不会改变旧参考或正在执行的任务。最多 16 条及字节预算限制单轮参考包，不限制个人收藏数量。
- 关闭标签、停止实例、取消收藏、解除空间连接和删除资源分别执行。解除连接遇到活动实例、可见标签或在途使用时说明依赖；删除有空间连接的资源同样拒绝，不隐式停止或级联删除。历史任务已经冻结的证据保留。
- 全部修改等待 Main 确认，错误行内保留，失败不清空输入；目录冲突提供重新读取路径，迟到查询不覆盖新版本。命令使用开始操作时的明确目标，切空间不改变目标。目录版本独立于空间布局版本。
- 复用 `Notice / ErrorToasts`、`btn`、`field`、原生 select 和 `ModalLayer`。表单 `noValidate`、错误关联字段、无效提交聚焦首个错误、中文 IME 安全；搜索清除返回输入焦点。删除通过 app-owned dialog，先聚焦取消，失败不关闭；Escape 与操作后焦点恢复沿用既有规则。
- `html-text-v1` 与 `rendered-dom-text-v1` 保留各自来源身份，不将 guest 页面标成宿主页面。没有正文的链接明确显示未保存快照，不用“捕获失败”阻止个人收藏管理。
- 实测按 R01–R14 覆盖模型、迁移、Main/service/MCP、Electron 完整流程、错误/键盘/窄窗/主题。真实模型与 sandbox live 仍需单独授权，fixture 不替代真实服务验收。

## 统一观察与资源环境（INTEGRATION-1）

- 新建文件或终端时明确选择已配置环境；显示环境名称及可用能力。未配置本地根或SSH配置时给出不可用原因，不使用home、不复制认证，也不从终端输入推导授权。运行绑定属于当前空间与环境，切空间不能重指向已有实例；账户资源通过连接在空间使用，连接不增加权限。
- 文件标签仅浏览授权根内的目录和读取内容，不提供编辑/保存。路径、内容来源、范围、散列和截断可见；续读使用已有游标，内容变化时显示失效并要求重新读取。watch提示“可能变化”，不能用无提示表示内容未变。SFTP没有watch时明确说明。
- 终端资源使用本地、sandbox或SSH之一；UI与观察读取同一实际PTY。连接/关闭/重连为明确动作，关闭标签保留实例；重启只恢复资源描述，不自动执行shell。SSH断线后的远端进程状态不明时显示未确认，重连明确拒绝，不能宣称已清理。连接尚未取得终端适配器就失败时，服务明确证明未创建进程，允许用户重试；错误文字本身不能充当清理证明。
- 会话的上下文区域提供观察入口，选择本空间实际资源及适合该类型的读取动作，显示来源、范围、结果、时间及更新提示。观察成功不自动发送消息、启动任务、标记通知已读或接受结果；结果归属请求开始时的空间、会话和运行。
- 读取期间给出忙态和取消入口，重复提交受限；取消、切空间、替换实例后的迟到结果不能覆盖新的上下文。取消保留之前已完成的证据；证据只追加，不覆写。失败保持用户输入和可重试状态，明确区分无权限、不可用、过期与截断。
- 复用现有按钮、行内状态、原生select、ModalLayer与原生网页遮挡集合。文件读取和观察不新增全局板块、右侧会话、空间主题入口或悬浮终端。新增表单使用noValidate、中文标签和IME安全提交；搜索有可见清除按钮，长资源名/路径能换行或完整查看。
- 资源 MCP 按 Main 注册的会话归属与本轮冻结参考包授权，不继承其他空间或整个账户收藏。统一观察继续按 Main 注册的空间、环境和实例授权；收藏正文与实时观察分别保留身份，不互相替代。

## 比赛环境安装与配置

首次正式包启动且环境未就绪时进入设置中的“比赛环境安装”，复用现有 field、btn、Notice 和滚动区域。Main 是安装进度、已登记沙箱和运行配置的唯一写入者；长任务状态来自 setup:status，离开设置不取消安装。取消操作只在所属子进程退出确认后显示终态；进程退出未知时保留登录身份，阻止新安装操作。重启不重放登录或沙箱创建，用户重试先核对实际资源。

首次准备先检查系统、签名和载荷，再准备 sbx，停在 Docker 登录；已有登录可以明确继续。工具探针通过且已有模型凭据仅表示配置就绪，不表示真实模型回复通过。OpenAI OAuth 只在用户勾选全局凭据更新并点击登录后运行；输出留在系统终端，应用只记录所属登录操作和退出码。

本地目录通过系统选择器授权；renderer 不能提交未选择的新路径。SSH 表单只保存连接参数和可信指纹，使用已有 SSH agent，不保存私钥。无效表单保留输入，显示字段错误并聚焦第一个错误字段。保存成功留在设置，明确提示重启后生效；旧会话和资源继续使用启动时配置。设置始终挂载，切换页面保留未提交的表单。
