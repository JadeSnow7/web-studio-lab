# Docker Sandboxes 本机安装与独立沙箱验证

2026-10-06。用户授权安装 sbx、补充仓库依赖及安装命令、在独立沙箱准备 Codex CLI 与必要组件，并测试其工作与读取沙箱内文件的能力。

## 范围与基线

- 保留当前工作树的 Codex 对话实现及其他未提交内容；实现前文件指纹见 `.local/sbx-verification/2026-10-06/baseline.json`。
- 本轮验证独立沙箱，不接入 Web Studio 产品运行通路，不提交或推送。
- 不直接挂载项目、用户 HOME 或凭据目录。测试数据为专门创建的无敏感内容文件。
- 认证使用官方宿主流程，不读取或复制现有 Codex 凭据。若必须由用户完成交互登录，明确记录阻塞并继续可独立执行的检查。
- 保留安装失败、权限拒绝和测试原始输出；只有真实执行成功才记为通过。

## 固定测试基准

| 编号   | 方法与通过条件                                                                                                                        |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| SBX-01 | 安装官方 sbx，版本和帮助命令正常；记录来源、版本与安装位置。                                                                          |
| SBX-02 | 创建本轮唯一命名的 mountless 沙箱；记录身份和挂载事实，确认未提供宿主工作区。                                                         |
| SBX-03 | 在沙箱内执行 Linux 环境及 Codex、Node、Git 等必要组件检查；安装或使用模板提供的组件并记录实际版本。                                   |
| SBX-04 | 在沙箱内新建带随机校验词的文件；用普通命令读取成功。宿主专用测试文件不应以其宿主绝对路径直接可读。                                    |
| SBX-05 | Codex 的提示只给文件路径、不包含校验词；真实工具读取该文件，助手回复匹配校验词，具有完成事件且退出码 0。保存 JSONL/工具事件作为证据。 |
| SBX-06 | 导出测试产物并检查内容；停止沙箱、核验停止状态，保留可复验信息。                                                                      |

模型调用、普通命令读取、挂载检查是独立证据；普通 shell 成功不能代替 Codex 模型通过。单一测试目录不可达也不能证明完整隔离安全性。
