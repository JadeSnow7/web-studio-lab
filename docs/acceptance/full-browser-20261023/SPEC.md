# 应用内完整浏览（BROWSER-1）

2026-10-23 用户授权直接实现、验证，保留已有未提交修改，不提交或推送。本合同替代普通网页的只读 HTTPS 文档展示约定；受管 App、工作台 IPC、账户资源归属及 Agent 写入授权仍遵循各自合同。实测结论见 [验证记录](README.md)。

## 行为和所有者

- 空间网页由 Main `WorkbenchHost` 与 `PreviewController` 管理，Renderer `Browser` 只负责地址输入、导航按钮、布局与状态展示。沿用现有地址栏的 IME、重复提交和迟到响应规则，不重做工作台样式。
- 普通网页通过 Chromium 原生 HTTP/HTTPS 加载，保留网站样式、脚本、图片、frame、表单提交、fetch、WebSocket 与同文档导航。用户可以在网页内搜索和登录。输入域名补全 HTTPS；地址栏关键词使用百度搜索，提交前不发送输入。
- 同一空间普通网页及其弹窗共享稳定的持久 session。Cookie 与网站存储按网站自身规则保存，重开标签或应用后可恢复持久登录；不同空间、工作台默认 session、受管 App 分区互不共享。网页浏览不会复制系统浏览器账号或登录其他真实账号。
- `window.open`、新窗口链接及登录弹窗在应用内打开，保留 opener/postMessage 和窗口关闭行为。子窗口显示真实来源，不把网页标题作为可信来源；跟随所属浏览器实例销毁。关闭标签仍按既有规则保留后台实例。
- 原生网页和子窗口没有工作台 preload，保持 sandbox、contextIsolation、webSecurity，关闭 Node 集成；网页不能使用工作台 API。拒绝文件和系统外部协议，不调用系统浏览器；设备权限默认拒绝，下载不在本轮开放。
- 普通网页采用原生浏览器网络语义，可导航 HTTP/HTTPS 网络地址；不再经过旧 Node HTTPS 代理，不继续宣称 DNS 固定 IP、仅公网 443 和只读请求保证。证书校验、同源和混合内容约束仍由 Chromium 执行，不关闭这些约束换取站点兼容性。
- 受管 App 使用独立临时 session，其网络访问仍绑定当前实例的精确 origin 与租约。普通网站登录和交互不授予 Agent 控制面写入权限。
- “保存正文快照”只在用户明确操作时读取当前实际页面的可见正文与标题，核对页面身份、导航代次和加载状态；不采集 Cookie、密码框或其他输入值。保留 64 KiB 正文预算、截断标记、散列和不可变版本。新快照必须区分 DOM 来源与历史 HTTP 响应来源。
- 新宿主快照使用 `host-rendered-dom-text-v1` / `rendered-visible-text`；`sourceSha256` 对有界采集结果 `{title,text,truncated}` 的 JSON 求散列，`contentSha256` 对最终 64 KiB 内正文求散列。它不表示网络响应原始字节；历史 `html-text-v1` 与 guest 快照继续按原有变体读取。

## 固定验收

| 编号 | 输入与操作                                                | 必须观察到的结果                                              |
| ---- | --------------------------------------------------------- | ------------------------------------------------------------- |
| B01  | 真 Electron 窗口访问受控 HTTP 网站                        | 原始 CSS、图片、JS、frame、异步请求和页面按钮工作，无只读模板 |
| B02  | 页面搜索表单、地址栏域名/关键词、带 hash 导航             | 正确 URL 和结果；提交只发生一次；hash 不被丢弃                |
| B03  | fixture 用户登录、刷新、同空间第二网页、应用重启          | POST 与 Cookie/存储正常；持久账号状态可恢复；跨空间不可见     |
| B04  | 弹窗认证、新窗口链接、opener/postMessage、自关闭          | 窗口属于应用；会话共享；父页收到结果；无外部浏览器调用        |
| B05  | 后退、前进、刷新、加载失败后重新导航                      | 历史和地址保持一致；失败可见且可恢复；窄窗仍可使用            |
| B06  | file/javascript/自定义协议、工作台 API、受管 App 过期租约 | 非法来源不能获得工作台能力、打开外部程序或复用 App 授权       |
| B07  | 动态正文保存、采集中导航、历史快照读取                    | 当前正文与来源正确；迟到结果拒绝；旧版本仍可读取              |
| B08  | 公网真实网站搜索                                          | 原生显示与页面交互实测；记录实际站点、结果和网络/站点限制     |

本地 fixture 登录验证浏览器机制，不代表第三方账号登录已验收。真实账号、验证码、第三方 OAuth 的站点风控和嵌入式浏览器限制只能按实际结果报告，不绕过站点限制。默认检查不调用模型或真实 sandbox。
