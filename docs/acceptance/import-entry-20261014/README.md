本轮把已有 edu-web 适配整理为“选择本地 Git 根目录 → 静态预览 → 明确确认 → 隔离复制并启动 → 学生页”的产品入口。只支持 edu-web profile v1，不是通用项目导入器。原标准应用创建入口继续保留。

## 用户可观察结果

从空间“新建 App”选择“导入 edu 工程”。预览显示支持的运行方案、源码数量/大小和安全边界；来源详情可展开。确认前不创建项目或连接 guest；不执行所选项目脚本。来源变化、缺少文件、无效 Git 或不支持项目显示原因并可重新选择。

确认后使用独立项目，保留原目录。进度区区分复制与启动。重复点击受限；关闭/Escape只收起，显式取消等待清理，已发布副本保留。失败按实际发布事实提供导入或启动重试。只有用户仍停留在本次可见对话框和原空间时，成功才自动打开学生页；迟到完成不能重开或抢占当前页面。

## 复验

按照根 [AGENTS](../../../AGENTS.md) 准备依赖和已授权的独占 guest。普通测试不需要真实 sandbox：

```sh
pnpm build
env -u ELECTRON_RUN_AS_NODE pnpm exec playwright test e2e/edu-app-ui.spec.ts
```

真实测试需显式 `WSL_EDU_LIVE=1`、`WSL_SBX_NAME=wsl-edu-...`、`WSL_EDU_SOURCE_ROOT`、准确的 `WSL_EDU_EXPECTED_SHA256`、不存在的绝对目录 `WSL_EDU_EVIDENCE`，可另指定全新 `WSL_EDU_PROFILE`：

```sh
env -u ELECTRON_RUN_AS_NODE pnpm exec playwright test e2e/edu-app-live.spec.ts
```

普通和 live 测试须串行运行。live 脚本记录构建摘要、来源摘要、预览与自动学生页、进程/端口和导出清单，失败及清理失败保持为失败，不把 skip 算通过。全量 `pnpm check` 遇原始历史档案问题时保留失败，按贡献规范独立运行后续命令。
