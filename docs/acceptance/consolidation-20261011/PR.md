## 变化

空间资源、受管 App 控制面及 App 名称/说明原先分散在未发布提交和不同工作树中。本 PR 将有效增量合并到现有 Main 状态模型：用户可编辑 App 描述，任务固定 App 与工程身份，执行器按实际实例操作 CLI、数据与界面；切换空间、导航和取消后，迟到响应不能成功归入新对象。

- 汇总资源收藏与空间连接、不可变引用、模板/安装和退出清理的已有未发布提交；保留既有界面结构和来源记录。
- 接入 App CLI/data/UI 控制面及模板 Agent 桥接；生产构建剔除 Agent UI 桥接。
- 增加空间 App 元数据和编辑表单，冻结任务 App/project/guestCwd 与页面/元素上下文；编辑描述不改变实例运行状态。
- 修复异步结果归属、对象清理期间导航/取消、CLI admission 期间停止的竞态。
- 将两个已存在的 schema3 格式显式迁移为 schema4，保留 catalog、App、旧资源与原字节备份；损坏和未来格式拒绝覆盖。
