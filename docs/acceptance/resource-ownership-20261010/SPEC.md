## 2. 归属及身份

| 对象 | 权威与不变量 |
| --- | --- |
| Resource | 账户拥有的可重开描述；全局 resourceId 与 ownerAccountId；类型为网页、文档/文件入口、开发资源（项目或已有终端/SSH连接描述）。无空间所有权，不包含进程句柄或凭据。 |
| LibraryEntry | 当前账户主动收藏的 resourceId；不存在条目不等于资源被删除。全局资源页只列这些条目。 |
| WorkspaceResourceLink | workspaceId + resourceId 唯一；空间内引用关系，可绑定明确 referenceVersion。连接不创建实例、不授予额外权限、不自动选择为 Agent 参考。 |
| ResourceRevision | 不可变内容版本，保留捕获身份、时间、摘要、截断和非可信正文。更新追加版本；旧任务及空间固定版本不变。 |
| 运行绑定/ResourceInstance | 空间、环境和全局资源的绑定，持有 instanceId/generation 等运行事实；每空间独立。已有 WorkbenchResource.resourceId 可继续作为运行绑定 ID，以保留历史观察/任务身份；新增 catalogResourceId 明确指向账户资源。不得把这两个 ID 当作同一概念。 |
| View/Tab | 引用运行绑定的展示状态；关闭标签不取消收藏、不解除连接、不隐式停止实例。 |
| Session | 保持会话模型，旧 session 类型的展示绑定不迁成个人收藏。 |

Main 的应用用例是唯一业务写入者；service 仅执行捕获/读取/进程操作和只读旧数据导入。新资源、收藏、连接和版本由同一版本化持久化提交保存，失败不得发布半完成业务快照。正文按需查询，正常列表/事件不得复制全部正文。

空间专属是“只连接本空间且未收藏”的使用状态，不是另一种所有者。收藏同一对象不复制正文；连接另一空间不复用第一个空间的登录会话、PTY 或实例。受管项目的物理环境及生命周期约束不因收藏或连接而改变，不能把预览 URL 当成独立可跨空间启动的项目副本。

## 3. 应用接口合同

具名命令沿用窄 IPC 和现有 Main 来源检查。个人命令不要求 workspaceId；ownerAccountId 从可信本地上下文取得。边界 schema 拒绝未知字段和非法身份，内部信任已验证类型。

| 用例 | 输入语义 | 结果 |
| --- | --- | --- |
| 查询个人收藏 | 分类/搜索由投影过滤；无空间前置条件 | 账户收藏摘要、连接空间及目录 revision；正文按需取 |
| 收藏链接 | title/url/commandId/expectedCatalogRevision | 创建或显式复用账户网页描述并收藏；不捕获、不打开 |
| 收藏已有资源 | resourceId 或指定空间运行绑定 | 增加 LibraryEntry，保留空间关系；重复提交不重复创建 |
| 取消收藏 | resourceId/expectedCatalogRevision | 仅移除 LibraryEntry |
| 更新描述 | resourceId/title/expectedCatalogRevision | 修改账户标题；不修改已捕获来源证据，不通过改 URL 替换旧资源身份 |
| 连接到空间 | workspaceId/resourceId | 幂等建立连接；不启动实例 |
| 从空间移除 | workspaceId/resourceId | 仅解除连接；有活跃实例、可见标签或在途使用时拒绝并说明如何先处理，不隐式停止 |
| 在空间打开 | workspaceId/resourceId | 校验现有能力，创建或复用该空间运行绑定/标签；跨空间实例隔离 |
| 保存正文快照 | workspaceId/runtimeResourceId/expectedCatalogRevision | Main 核对实际页面身份，调用捕获端口，追加不可变版本；不自动收藏或提供给 Agent |
| 选择空间参考 | workspaceId/resourceId/version 或 null | 固定明确内容版本，null 取消；不选择未连接资源 |
| 删除资源 | resourceId/expectedCatalogRevision | 仅无空间连接、无活动实例时可删除目录项；保留历史任务已冻结的证据；UI 使用现有确认框 |
| 个人会话参考 | 明确 resourceId/version 列表 | Main 只允许当前收藏的内容版本；发送时冻结，默认空列表 |

命令 ID 及 revision 遵循现有去重/冲突语义；目录 revision 与空间布局 revision 分开，切标签不使收藏冲突。资源错误属于该用例，不污染无关空间错误。最终退役 capturePublicResource/removePublicResource 等旧空间集合写入接口，不保留双写兼容层；只有旧数据读取 schema 可保留。

## 4. 会话与权限

空间会话只取得该空间已连接且 referenceVersion 非空的内容；个人会话只取得用户明确选择的收藏。Main 在发送/执行前冻结账户、空间（个人为 null）、会话与资源版本，service 核对注册会话归属并封装 generation/turnId 后传给只读 MCP。移除 taskflow-demo 硬编码，不能仅放宽字符串校验而失去归属验证。

每轮最多 16 个参考、单正文 64 KiB、完整包 512 KiB，继续按 UTF-8/完整 JSON 字节校验；收藏数量不继承 16 条限制。超过预算明确拒绝发送，不静默截掉选中的资源。参考变化只影响下一轮，运行中的冻结包与已保存历史不变。网页文本、文件文本均不能增加工具或环境权限。

## 5. 迁移

读取旧 workbench 和 space-resources 数据，先验证格式、摘要和身份，再构造一个完整新状态原子提交。成功标记与新数据在同一提交中；失败保留旧文件、当前可读状态和明确错误，重复启动/重试不重复导入。未知较新 schema 不得覆盖为空文件。

旧公开网页 -> 账户资源 + 原空间连接，默认不收藏；保留旧 ID、版本、摘要和来源，不仅凭 URL 合并。为延续旧空间已选择的参考行为，导入的连接固定旧内容版本，UI 显示为参考资料。旧工作台非会话资源 -> 账户描述 + 空间连接 + 原运行绑定 ID；不恢复旧运行进程。相同 URL 的已打开页面与旧快照不擅自合并，可由后续显式更新建立关联。旧文件原样保留为只读迁移来源，不能继续被新业务写入。

## 6. 页面合同及组件所有权

沿用 DESIGN.md、app.css token、btn/field/Notice/Icon、ModalLayer 和原生 select。资源页标题“我的资源”，分类“全部/开发资源/网页/文档”；支持搜索及显式清除、受控分页、空态/无结果/错误/忙态、详情、连接与取消收藏。过滤和页码为本地展示状态，不放进空间状态或 URL（Electron 本地路由）。

空间侧栏在活跃标签之外提供折叠“空间资源”，区分本空间内容与收藏连接，并显示参考版本；原“后台资源/已关闭标签”继续表达实例事实。连接/收藏不自动打开标签。浏览器分开“收藏到资源”“加入空间/空间资源”“保存正文快照”；无法捕获正文不妨碍保存链接。

所有入口使用相同用例和文案。失败保留表单并显示行内错误，忙态禁止重复提交；中文 IME 不触发提交。选择空间的操作绑定用户实际选中的 ID，切空间/迟到响应不得改错对象。删除使用现有确认框、初始取消焦点、Escape 与触发器焦点恢复。窄窗长 URL/标题可换行，沿用内容滚动；主题不产生新 token。
