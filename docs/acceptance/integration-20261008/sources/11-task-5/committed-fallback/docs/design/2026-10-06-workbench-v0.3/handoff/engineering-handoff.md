需要工程明确处理的四项：

1. **迟到截图竞态**：freeze在await后无条件隐藏视图；改为最新布局意图拥有最终决定权。原型验证仅验证该交互规则，需原生Electron复现、修正并复验。
2. **CDP确认门槛**：现有freshness比较webContents/文档代次，没有控制中断代次。断开立即使现场失效；重附着不能恢复旧现场确认资格。[workbench:55–79](../../../../apps/desktop/src/renderer/src/state/workbench.ts#L55)、[controller:110–113](../../../../apps/desktop/src/main/preview/controller.ts#L110)。
3. **弹窗焦点**：现有aria-modal和Esc不能证明焦点闭环。需真实Tab/Shift+Tab、背景交互拦截、关闭后焦点恢复验证。
4. **证据追踪**：[历史验证表](../../../verification/2026-10-06-desktop-ui/README.md#L21)引用log，但[.gitignore:15](../../../../.gitignore#L15)忽略所有*.log。工程须提供仓库可追踪证据或版本绑定发布资产及相对引用，在干净检出中复核；本轮不改忽略规则、不改写历史“通过”。读取不到时明确“证据不可核对”。

模式契约冲突：计划§7.1与架构manifest列replay，实际协议只允许online/revalidate；设计把“历史查看”作为只读动作而非run mode，遵循计划§7.3及实际协议。工程需统一命名，不能自行添加兼容mode掩盖冲突。

本交接未扩展多Agent、云部署、社交协作、完整权限/编辑器、多页面编排；交互终端P1。拟补数据只用于闭环定位与复验，不扩成通用调度/追踪平台。
