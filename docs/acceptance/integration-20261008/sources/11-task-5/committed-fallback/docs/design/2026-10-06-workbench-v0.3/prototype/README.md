# v0.3 可编辑交互设计原型

11 张画板均为独立 `.dc.html` Design Component；`Main.dc.html` 承载整个共享状态流程，其余为同模板的独立起点变体。切换画板不传递状态，画板内部六模块导航保留状态。所有模拟状态常显“交互演示”，没有真实 API、模型、进程或消息操作。

## 本地启动

```sh
python3 serve.py --port 8766
```

仅监听 `127.0.0.1`；打开 `http://127.0.0.1:8766/Main.dc.html` 或 `index.html`。`support.js` 是 baseline 的内置 React / ReactDOM 的 `dc-runtime.js` 原样副本；页面不依赖 CDN 或外网。原平台的画布外壳不用于本地启动。

产品窗口本身为1440×900（或1024×720）；画面外演示控制条占约48px，因此本地全页查看需1440×948或1024×768，控制条不属于产品窗口。若浏览器可用高度更小，可通过文档滚动查看底部；产品各列另有内部滚动。

## 可编辑源与生成

- `template.html`：保留 `<x-dc>`、`helmet`、控制流与事件绑定，所有画板使用的标记和样式。
- `logic.js`：DCLogic 确定性状态与键盘/浮层约束；仅模板中 `__BOARD__` 由生成器替换。
- `generate.py`：使用 baseline 的11个原文件名、画板位置和顺序生成；所有板标为可交互，发布标题加 v0.3。
- `canvas.json` 与11个 `.dc.html`：回传 Claude Design 的权威发布包。不得仅回传截图或普通 HTML。

修改模板或逻辑后运行 `python3 generate.py`，再运行 `node check.mjs`。本地目录页和 loopback server 是预览辅助；无需把它们发布为额外画板。

## 操作路径

1. 默认空间页，点「点选页面元素」，再点页面「准备设计评审」。可看截图，再确认目标、范围、固定验收、补充条件与预算。
2. 确认 v1 后点「开始 Agent 修改演示」，画面外「推进下一阶段」分别推进命令退出、等待服务、ready、检查、通过。这里不使用自动计时隐藏阶段。
3. 查看各项证据，接受或要求修改。接受后进入历史；从完整来源创建无模型复验记录，再推进检查；原记录与接受不变，新复验记录人工决定为“不适用（复验）”，不开放接受或要求修改。
4. 运行时画面外注入「冷启动检查失败」，查看证据和反馈，再自动修复。保持同一 run、attempt2、累计预算；可展开旧 attempt1 证据。预算选择1次时失败后停止修复、等待清理回执、保留失败记录。
5. 取消时需推进清理回执；工具故障为无法判断，清理前禁止恢复，完整源码缺失则禁止复验。启动失败与超时独立。
6. 页面导航/CDP断开现场失效；重新附着仍不能确认，重采集才恢复。迟到截图可在快速开关或切页后注入，旧返回不能控制新界面。
7. C2/C3 展示冻结定义和确认版本，但本轮完整可点击执行只覆盖 C1，启动按钮明确禁用并说明。
8. 截图与证据弹窗背景 inert、Tab/Shift+Tab焦点闭环、Esc回触发按钮；窄窗右栏默认收起，与 Workshop 临时展开互斥。

## 画板与变体

| 文件 | 初始状态 / 变体 |
|---|---|
| Main | 未采集空间；覆盖主路径、失败修复、取消、工具故障、历史复验、各现场/布局变体 |
| RunPassed | 固定检查通过，待人工审阅；证据、接受、要求修改 |
| RunCancel | 冷启动失败；反馈修复与取消清理；异常注入 |
| RunHistory | 来源已接受只读记录；无模型复验新记录 |
| Home | 首页入口；返回空间 |
| Space | 未采集空间起点 |
| Overlay | 截图弹窗；键盘与临时侧栏变体 |
| Resources | 明确资源占位；返回主流程 |
| Conversations | 明确协作/消息后置占位 |
| Tasks | v1对应run及人工决定；版本只读 |
| Settings | 固定平台边界及设置占位 |

## 验证边界

`check.mjs` 对纯状态机与11画板结构进行21组检查，已通过。它不操作浏览器，不证明文字布局、弹窗键盘、DC runtime 渲染或发布兼容性；这些由主线程 CUA 实际验证。设计中的64位 hash、完整源码、证据与时间均为示例元数据，不表示实际源码快照或业务验收。原 Electron 原生视图、CDP、进程清理和真实固定检查未由这个原型验证。
