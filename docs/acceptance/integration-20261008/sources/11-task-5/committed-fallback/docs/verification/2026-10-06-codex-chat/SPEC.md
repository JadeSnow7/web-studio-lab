## 本轮交付

1. 窄 Codex CLI adapter：非交互 JSONL 协议、stdin 传提示、真实会话标识、显式错误与受控取消。业务逻辑不依赖 Electron；Electron 入口负责装配及 IPC。
2. `packages/protocol` 拥有跨进程 schema；preload 只暴露具名聊天接口，保持可信发送者检查、contextIsolation/sandbox 与预览页隔离。
3. 首页个人对话、会话页和空间右栏共用消息、忙碌与错误状态，只有同一会话共享内容。个人对话不隐式读取空间、页面快照或项目文件。
4. 可发消息、接收真实回复、继续上下文、取消等待、开始新对话；重复提交受控，输入法确认不会误发送。CLI 不存在、未登录、启动/协议/模型失败时显示原因，保留已输入内容或用户消息。
5. `chat` 可用性独立于 `execution`。真实任务执行、自动改码、Browser 工具、验收和接受流程不因聊天成功而宣称可用。演示消息不得混入真实会话历史。
6. 同步 README 使用入口及验证报告。保持本地交付，不提交、推送或打包发布。

## 状态与约束

- 服务拥有会话与当前请求身份；renderer 只保存其投影和用户草稿。
- 收到模型文本不代表整轮成功；成功必须有协议完成事件且进程正常退出。进程失败、缺完成事件或 malformed JSON 不可伪装成功。
- 取消后等待所属子进程退出；旧请求事件不能回填新会话。关闭窗口也应清理其进程。
- 复用 CLI 自己管理的登录，不读取或复制密钥。聊天使用只读权限，不自动附带项目内容，不加载第三方工具/钩子来扩大此切片范围。
- 本轮不承诺应用重启后恢复聊天历史；若仅保留进程内历史，界面/说明应如实标明。
