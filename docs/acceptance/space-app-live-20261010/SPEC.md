## 固定验收

1. 通过产品 UI 创建 App，真实沙箱产生独立工程；原生 Browser 展示运行页面，健康接口身份与 Main 保存的项目一致。
2. 在该 App 原生页面点选标题，采集到关联会话；确认任务保存实际 capture 元素、页面身份及 Main 绑定的 App 工程。
3. 从产品任务入口启动真实模型，目标仅替换当前工程 `src/App.tsx` 的标题为本次唯一文本。检查实际工具执行、任务完成及清理状态，不能以助手自述替代修改证据。
4. 读取工程前后源码清单，确认只出现指定标题修改；保留原始证据。停止并重新启动同一 App，以新运行实例验证构建后原生页面显示新标题。
5. 测试使用隔离用户数据和新建项目；只取消/停止本轮拥有的任务与应用。记录清理 ACK、进程/端口证据；不停止共享沙箱。

上一轮本地验证保留在 `../space-app-model-20261010/`。本轮原始失败与后续通过分别留档，不覆盖。自动化真实运行不等于用户接受，也不包含安装包、发布或部署验收。
