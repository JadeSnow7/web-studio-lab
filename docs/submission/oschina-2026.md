## 一、技术创新（30%）

### 工作空间与事实归属

首页、空间、资源、会话、任务和设置直接可达。升级后的空间能力限定在空间页：切换器、垂直标签和最多四个窗格保留资源身份；关闭标签仅隐藏视图。右侧仅通知，打开和标记已读不推导任务执行、检查通过或人工接受。主题仅在设置页按空间保存。

Main WorkbenchApplication 唯一管理空间、资源描述、会话、任务版本、运行与持久化。renderer处理投影和临时输入，Node服务管理Codex、PTY、文件与协议适配。观察请求冻结空间、会话、运行、环境、资源及实例代次，避免切换焦点后把迟到结果归给新对象。这是整合契约；具体接线和验证状态分别见[E14](oschina-2026-evidence.md#e14)。

### 观察与验证分开

观察能力从实际WebContents、同一PTY流和显式授权根读取内容，返回范围、截断、内容散列或失效提示。观察结果只是有来源的上下文，不是业务验收通过。文件watch属于有损变化提示，SSH必须使用可信主机key pin与已配置认证；没有配置时不可用。[E14](oschina-2026-evidence.md#e14)

VS001是独立的固定验收基准：冻结输入与允许修改的文件，验收端独立连接指定CDP target、读取页面、执行postcondition并采集证据。未来产品adapter不能代交DOM结果或passed布尔值；当前仍未实现这个adapter。[E02](oschina-2026-evidence.md#e02) [E05](oschina-2026-evidence.md#e05)

任务、运行和产物用身份与SHA-256绑定，合成自检检出串用、篡改和缺失。哈希能发现变化，不能独立证明执行真实性。目前没有效率、真实任务成功率或同类工具对照数据，不提出量化优势结论。[E06](oschina-2026-evidence.md#e06) [E07](oschina-2026-evidence.md#e07)

## 二、场景落地（30%）

### 当前可运行范围

在macOS Apple Silicon上，按[当前README](../../README.md)和[依赖说明](../development/dependencies.md)安装与启动。当前安装入口为pnpm，历史VS001的npm锁仅用于原快照溯源。

```sh
pnpm install --frozen-lockfile
WSL_SBX_NAME=wsl-sbx-smoke-20261006 pnpm dev
```

真实对话需本机已有sbx、guest Codex、认证和网络；普通回归使用明确标注的fixture。文件、终端和SSH使用已配置环境，观察和资源能力是否完成本轮真实验证以E14为准，不从测试入口存在推定通过。

### 已有证据和未完成闭环

空间重制基准检查包含真实Electron窗口回归，发现的窄窗时序失败保留原始记录。Provider阶段类型、构建和341项单元通过，8项live跳过；这些结果只适用于其源码指纹，最终整合需重新运行完整验证。[E14](oschina-2026-evidence.md#e14)

VS001固定任务仍是把唯一可见标题从 `Hello baseline` 改为 `Hello Web Studio`。2026-10-07归档 `78531515-547a-4d5e-a572-ff6efbf2a80b` 自检8/8通过，B01–B05均为 `failed / target_missing / performed=false`；没有真实Agent/CDP正向验收或截图。其基准SHA-256为 `e6e980c11e0ac84baf26c52b5724a9a6706e3de480494aba549293425a2ab928`。本轮保留原字节与结论。[E09](oschina-2026-evidence.md#e09) [E10](oschina-2026-evidence.md#e10)

产品adapter、母模板和独立检查器接入后，必须在同一固定输入和判定条件下获得新的B01–B05全部通过记录。现有聊天、PTY、原生网页或统一观察通过不能替代该闭环，也不能推广为完整IDE或生产远程验收。
