# 内置静态演示页面

`taskflow/` 是一组静态页面，只供工作台 Browser 区在没有生成 App 时演示加载、刷新、导航、点选与截图。

- 由 Electron 主进程通过 `wsl-demo://taskflow/` 协议提供，只注册在 Browser 区的独立 session 上。
- 不是已接入的标准母模板（`templates/standard-app`），不读写数据库，也不调用任何 API。
- 页面里的任务、成员和截止日期都是固定示例。“截止日期”一列故意读取了错误字段 `deadline`，用来演示 C3 的现象和控制台错误采集，不代表 C3 fixture。
- 不参与固定验收，也不能作为任何用例通过的证据。

实际魔塔与手帐场景的步骤、成片状态、倍速和人工操作说明见[演示与复现说明](../docs/submission/demo-guide.md)；本目录的静态 TaskFlow 页面不能替代这些真实运行证据。

2026-10-16 本地交付已包含 84 秒魔塔片和 130 秒手帐两段片；手帐第二段使用 18 日补录。视频回执、失败与收尾限制由参赛证据索引分别记录，本目录仍只是静态演示输入。
